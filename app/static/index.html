PDF → Guitar Pro 5

Converte tablaturas em PDF (texto ou exportadas de editores) para ficheiros .gp5. O ficheiro é processado em memória e não é guardado.

Tracks (ordem no ficheiro GP5)
    Metadados (detetados no PDF — pode corrigir)
    Ritmo

    Se o PDF tiver a notação rítmica (hastes e colcheias por baixo da tab), as durações são lidas diretamente. Caso contrário: “Pelo espaçamento” estima as durações pela posição das notas dentro de cada compasso; “Duração fixa” atribui a mesma duração a todas as notas.

    Resultado

    Descarregar .gp5

    Avisos

      Partitura

      Clique numa nota para começar a tocar a partir daí. Partitura desenhada com alphaTab.

      Confirme as notas antes de usar. Legenda da pré-visualização: W/H/Q/E/S/T = semibreve…fusa, “.” = pontuada, minúsculas = pausa, (n) = ligadura/ghost, h = hammer/pull, / = slide, b = bend, ~ = vibrato.

      Suporta PDFs com texto. PDFs digitalizados (imagem) não são suportados.
