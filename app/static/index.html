PDF → Guitar Pro 5

Converte tablaturas em PDF (texto ou exportadas de editores) para ficheiros .gp5. O ficheiro é processado em memória e não é guardado.

Metadados
Instrumento
Ritmo

Tablaturas raramente indicam ritmo. “Pelo espaçamento” estima as durações pela posição das notas dentro de cada compasso; “Duração fixa” atribui a mesma duração a todas as notas.

Resultado

Descarregar .gp5

    Pré-visualização

    Confirme as notas antes de usar. Legenda: W/H/Q/E/S/T = semibreve…fusa, “.” = pontuada, minúsculas = pausa, (n) = ligadura/ghost, h = hammer/pull, / = slide, b = bend, ~ = vibrato.
