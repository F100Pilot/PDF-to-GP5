# Security · Segurança

**English** — Please do not report vulnerabilities in a public issue. Use GitHub's
[private vulnerability reporting](https://github.com/F100Pilot/PDF-to-GP5/security/advisories/new),
with the steps to reproduce and the version affected (Settings → About). Only the latest release is
supported.

The app is meant to run on your own computer (`127.0.0.1`). If you publish it on a server, read the
"Security" section of the [technical documentation](docs/TECHNICAL.md) first.

**Português** — Não relate vulnerabilidades numa issue pública. Use o
[relato privado de vulnerabilidades](https://github.com/F100Pilot/PDF-to-GP5/security/advisories/new)
do GitHub, com os passos para reproduzir e a versão afetada (Definições → Sobre). Só a última versão
publicada é suportada.

A aplicação foi feita para correr no seu computador (`127.0.0.1`). Se a publicar num servidor, leia
primeiro a secção "Segurança" da [documentação técnica](docs/TECNICO.md).
